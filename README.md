# FrailtyTester

A digital health assessment platform for frailty screening and clinical decision support.

## Features

- Evidence-based frailty assessment questionnaires
- Health metrics tracking with longitudinal views
- Results visualization — charts and risk scoring
- Patient data management
- Clinical decision support based on assessment outcomes

## Tech Stack

- JavaScript frontend
- Health assessment scoring algorithms
- Data visualization (Chart.js)
- Responsive web design — works on tablet and desktop

## Use Case

Designed for clinical environments where healthcare providers need a fast, structured way to assess patient frailty levels and track changes over time. The platform implements standardized frailty indices and outputs actionable risk scores.

## Setup

```bash
git clone https://github.com/JithendraNara/FrailtyTester.git
cd FrailtyTester
# Open index.html in a browser, or serve with any static server
npx serve .
```
